# Version française — Recharge non reçue ou code refusé

> ⚠️ **Fiche fictive** rédigée pour le projet académique DarijaCare. Elle ne décrit pas la procédure d'un opérateur réel et ne contient ni prix, ni numéro, ni engagement réels.

## Objet

Aider le client dont la recharge n'a pas été créditée ou dont le code de recharge est refusé.

## Étapes

1. Vérifier le solde après quelques minutes (le crédit peut arriver avec un léger retard).
2. Revérifier le code saisi (chiffres inversés, espace en trop) et réessayer une seule fois.
3. Pour une recharge en ligne ou mobile money, retrouver la référence de la transaction ou le reçu.
4. Si la recharge n'arrive toujours pas, déposer une réclamation « Recharge non reçue » avec le code ou la référence.

## Conditions

- Garder la carte de recharge ou le reçu jusqu'à la résolution.
- La recharge doit avoir été faite vers le bon numéro.

## Limites

- L'assistant ne peut pas créditer une ligne ni vérifier un code.
- Plusieurs essais avec un mauvais code peuvent bloquer temporairement la recharge par code.

## Escalade

De l'argent est en jeu ; si le crédit n'est pas arrivé après le délai normal, transmettre à un conseiller.

# النسخة بالدارجة — الشحن ما وصلش ولا الكود ما دازش

> ⚠️ **بطاقة خيالية** مكتوبة للمشروع الجامعي DarijaCare. ما كتوصفش الإجراءات ديال شي أوبيراتور حقيقي، وما فيها لا أثمنة لا أرقام لا التزامات حقيقية.

## الهدف

نعاونو الكليان اللي الشحن ديالو ما دخلش للرصيد ولا الكود ديالو ما تقبلش.

## الخطوات

1. شوف الصولد من بعد شي دقايق (الرصيد يقدر يتعطل شوية).
2. عاود شوف الكود اللي دخلتي (أرقام مقلوبين، فراغ زايد) وعاود جرب مرة وحدة.
3. إلا شارجيتي فالأنترنيت ولا بالموبايل موني، لقى المرجع ديال العملية ولا الوصل.
4. إلا الشحن باقي ما وصلش، دير شكاية «شحن ما وصلش» مع الكود ولا المرجع.

## الشروط

- احتافظ بالكارط ديال الشحن ولا الوصل حتى يتحل المشكل.
- خاص الشحن يكون تدار للرقم الصحيح.

## الحدود

- المساعد ما يقدرش يزيد الرصيد ولا يتأكد من الكود.
- بزاف ديال المحاولات بكود غالط تقدر توقف الشحن بالكود لشي مدة.

## التحويل لمستشار

كاينة الفلوس فالموضوع، إلا الرصيد ما وصلش من بعد الوقت العادي كنحولوك لمستشار.
