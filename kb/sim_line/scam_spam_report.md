# Version française — Signaler une arnaque, un spam ou un SMS frauduleux

> ⚠️ **Fiche fictive** rédigée pour le projet académique DarijaCare. Elle ne décrit pas la procédure d'un opérateur réel et ne contient ni prix, ni numéro, ni engagement réels.

## Objet

Procédure de sécurité face aux appels ou SMS d'arnaque (faux gains, faux conseiller, demande de code).

## Étapes

1. Ne jamais communiquer de code reçu par SMS, de code PIN, de mot de passe ni de données bancaires.
2. Ne pas rappeler le numéro et ne pas cliquer sur les liens reçus.
3. Signaler le numéro ou le SMS depuis la rubrique « Signaler une fraude » de l'application.
4. Bloquer le numéro dans le téléphone.
5. Si un code ou de l'argent a déjà été donné, demander immédiatement un conseiller pour sécuriser la ligne et le portefeuille.

## Conditions

- Un vrai conseiller ne demande jamais de code de confirmation ni de code PIN.

## Limites

- L'assistant ne peut pas identifier l'auteur d'une arnaque ni récupérer l'argent.

## Escalade

Cas sensible traité en priorité par un conseiller, surtout si de l'argent ou un code a été donné.

# النسخة بالدارجة — نبلغ على نصب، سبام ولا ميساج ديال التحايل

> ⚠️ **بطاقة خيالية** مكتوبة للمشروع الجامعي DarijaCare. ما كتوصفش الإجراءات ديال شي أوبيراتور حقيقي، وما فيها لا أثمنة لا أرقام لا التزامات حقيقية.

## الهدف

الإجراء ديال الأمان ملي كتوصلك مكالمات ولا ميساجات ديال النصب (ربح كذاب، مستشار كذاب، كيطلبو كود).

## الخطوات

1. عمرك ما تعطي شي كود جاك فميساج، الكود PIN، كلمة السر ولا المعلومات ديال البنكة.
2. ما تعاودش تعيط للنمرة وما تكليكيش على الروابط اللي وصلاتك.
3. بلغ على النمرة ولا الميساج من «بلغ على تحايل» فالتطبيق.
4. بلوكي النمرة فالتيليفون.
5. إلا عطيتي شي كود ولا شي فلوس، طلب فالحين مستشار باش يحمي الخط والمحفظة.

## الشروط

- المستشار الحقيقي عمرو ما كيطلب الكود ديال التأكيد ولا الكود PIN.

## الحدود

- المساعد ما يقدرش يعرف شكون اللي نصب ولا يرجع الفلوس.

## التحويل لمستشار

حالة حساسة كيعالجها مستشار بالأولوية، خصوصا إلا تعطات شي فلوس ولا شي كود.
